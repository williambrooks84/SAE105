# One Page Dynamique avec JSON et Templates  

Ce projet est une **one page** générée dynamiquement à l’aide de **composants et templates HTML**, avec du **CSS** et **JavaScript** pour l’interactivité. Les données sont stockées dans des **fichiers JSON** afin d’être affichées de manière dynamique.  

## Technologies utilisées  

- **HTML, CSS, JavaScript** : Structure, style et interactivité du projet.  
- **JSON** : Stockage des données dynamiques.  
- **Templates HTML** : Génération dynamique du contenu.  

## Utilisation  

Aucune installation requise.  
1. **Téléchargez** ou **clonez** le projet.  
2. **Ouvrez** le fichier `index.html` dans un navigateur.  

## Fonctionnalités  

- **One page dynamique** basée sur des **composants et templates HTML**.  
- **Affichage de données dynamiques** via des fichiers JSON.  
- **Mise en page et styles personnalisés** avec CSS.  
- **Interactivité et logique** avec JavaScript.  

---

Ce projet est simple à utiliser : il suffit d’ouvrir **index.html** pour voir son fonctionnement.
